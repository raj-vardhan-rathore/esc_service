# Solara Spa & Wellness — Demo Website

A mobile-first luxury spa and massage booking website built with React + Vite.

## Run locally
1. Install Node.js (18+ recommended).
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Build for deployment
Run `npm run build`. The production site will be in `dist/`.

## Before sharing with the client
- Replace the Solara name, logo, email, phone and Manila address.
- Replace sample service names, prices and durations with client-approved details.
- Replace demo therapist names and profile photos with real staff details and photos that the models and photographer have authorized for website use.
- The current photo URLs are remote Unsplash demo images; check each image's current license/usage terms and download appropriately licensed assets for production.
- Connect the booking form to a real booking service, CRM, email endpoint or WhatsApp flow. The current form is front-end demo only and does not send or store bookings.
- Add the client's privacy policy, terms, cancellation policy and any required business details.

## Notes
The therapist section presents staff profiles and treatment specialties; it is not a price list for people. All displayed prices are illustrative Philippine peso demo rates.
